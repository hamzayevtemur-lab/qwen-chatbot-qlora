# 💬 Qwen 2.5 AI Assistant

Interactive web chat interface for **[TemurbekHamzaev/qwen2.5-1.5b-chatbot](https://huggingface.co/TemurbekHamzaev/qwen2.5-1.5b-chatbot)**, a 1.5B conversational model fine-tuned using QLoRA parameter-efficient training on multi-turn dialogue data.

### Features
- ⚡ **Real-Time Token Streaming** via Hugging Face Serverless Inference API
- 🎨 **Modern Dark Glassmorphic UI**
- ⚙️ **Configurable System Persona, Temperature, and Max Tokens**
- 💻 **Syntax Highlighted Markdown & Code Blocks**
